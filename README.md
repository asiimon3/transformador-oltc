# Transformador 400/220 kV con cambiador de tomas en carga

Figura isométrica interactiva de una unidad monofásica de 400/220 kV con regulación automática de tomas en carga (OLTC).

- Versión clara: `index.html`
- Versión oscura: `oscuro.html`

Mueve el puntero (horizontal: tensión de red, vertical: carga) o usa las flechas; la barra espaciadora activa la cámara lenta para ver el ruptor.
